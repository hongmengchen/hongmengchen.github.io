# 项目目的

秩序创造自由，开源创造未来。

本项目以该信条为指导，利用 GitHub Pages 提供免费静态站点承载，以最小维护成本、最大可见性传播理念与知识，促进开放协作与长期可持续发展。

## 背景

在信息爆炸与工具快速迭代的时代，秩序（结构化、可重用的内容与流程）能够释放个体的创造力，让更多人专注于真正有价值的工作。本项目希望通过开源、共享与实践，把“秩序”转化为人人可用的工具和思维方式，从而创造更大的自由空间。

## 目标

- 搭建一个面向公众的静态站点，用于展示理念、项目、教程与实践案例。
- 提供可复用的内容模块与写作规范，降低贡献门槛，提升协作效率。
- 将 AI 作为生产力工具（辅助写作、内容组织、自动化部署等），而不是替代创造力。

## 受众

- 开源爱好者与内容创作者
- 希望使用简单流程提升生产力的个人或小团队
- 对“秩序即自由”理念感兴趣的研究者与实践者

## 技术与部署策略

- 托管：使用 GitHub Pages 承载静态站点（免费、稳定、与代码仓库直连）。
- 构建：使用现有前端工具链（例如 Vite + TypeScript）构建并输出到 `docs` 或 `gh-pages` 分支以供 Pages 发布。
- 自动化：通过 CI（例如 GitHub Actions 或 pnpm 脚本）实现构建与发布流水线，确保改动自动上线。
